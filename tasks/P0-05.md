# P0-05 集成测试及 P0 阶段验收

| 项目 | 内容 |
| --- | --- |
| 唯一编号 | P0-05 |
| 任务目标 | 复核已有 P0 交付，完成尚缺的本机 TCP 验收后提交阶段审核 |
| 前置依赖 | P0-01 至 P0-04 人工验收，前置验收基线全部包含于当前项目 HEAD |
| 开发范围 | 集成测试、受控本机服务验证、必要的测试修复与阶段报告 |
| 禁止修改范围 | 实际业务数据、生产部署、其他项目及 P1–P9。未经授权不得变更业务功能 |
| 输入条件 | 现有 P0 验收报告、ACCEPTANCE_CRITERIA.md、隔离临时库和允许本机回环监听的环境 |
| 预期输出 | 自动测试、数据库和真实 TCP 接口联调证据及阶段交付报告 |
| 实现要求 | 按 P0 标准逐项复核。实测 TCP 与替代协议测试分别记录。服务仅短时本机运行并结束 |
| 测试要求 | 全套 pytest、锁文件同步、Alembic 往返与检查、真实 TCP 健康/就绪、导入、详情、统计与接口文档 |
| 验收标准 | 所有必检项实测通过。P0 阶段完成由人工确认，其中 P1 启动需另行授权 |
| 失败处理 | 记录环境、复现命令及限制。TCP 或任一必检项阻塞时保留报告、暂停进入阶段验收 |
| 交付报告 | 测试总数、通过/失败/跳过、迁移状态、TCP 地址及响应证据、改动、风险与人工验收结论 |
