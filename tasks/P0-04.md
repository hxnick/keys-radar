# P0-04 基础 API 及查询统计

| 项目 | 内容 |
| --- | --- |
| 唯一编号 | P0-04 |
| 任务目标 | 复核已有基本入口、原始需求及证据查询、统计隔离和 OpenAPI |
| 前置依赖 | P0-03 人工验收，前置验收基线包含于当前项目 HEAD |
| 开发范围 | 健康、就绪、数据源、需求列表和详情、统计、错误响应、接口说明及测试 |
| 禁止修改范围 | 采集、分析模型、前端、外部部署、其他项目和 P1–P9 |
