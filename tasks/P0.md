# P0 基础工程及人工需求管理

建立 FastAPI、SQLAlchemy、SQLite、Alembic、Pydantic、配置和测试环境。迁移创建 data_sources、raw_posts、evidence_records、demand_signals、business_opportunities、opportunity_evidence、analysis_runs。原始需求通过单条、JSON 批量或 CSV 批量入库，校验字段与链接、规范化并计算哈希、按来源和数据性质去重。原始记录和证据一同提交。批次提供成功、重复和失败计数及错误明细。

交付健康、就绪、来源列表、单条录入、批量导入、需求列表、详情和统计。列表支持分页，需求支持按来源、数据类型、验证状态和模拟标识筛选。详情可查看原始证据。服务默认仅绑定回环地址。

验收覆盖依赖安装、空库初始化、升级和回退、模型和外键约束、三种导入、去重、非法数据、部分成功和意外回滚、筛选分页、模拟隔离、证据关联、健康、就绪、统计以及本机 HTTP 实测。测试使用隔离临时库和显式模拟数据。验收报告记录环境、路径、实际文件、测试结果、启动命令及未解决事项。P0 结束后等待人工确认是否进入 P1。
