# P0-03 人工需求导入及去重

| 项目 | 内容 |
| --- | --- |
| 唯一编号 | P0-03 |
| 任务目标 | 复核已有单条、JSON 和 CSV 导入的去重、异常处理与证据原子性 |
| 前置依赖 | P0-02 人工验收，前置验收基线包含于当前项目 HEAD |
| 开发范围 | 请求模型、人工导入实现与入口、导入文档及测试 |
| 禁止修改范围 | 需求自动采集、来源平台接入、业务模型调用、其他 API 和 P1–P9 |
| 输入条件 | 已验收数据库结构、CSV 与 JSON 字段约定和临时模拟样本 |
| 预期输出 | 可追溯的录入和批量导入行为，明确错误与事务口径 |
| 实现要求 | 校验必填字段、日期和链接，保留已有证据，按来源及模拟状态去重。验证有效行、重复行、失败行统计与异常批次回滚 |
| 测试要求 | 验证三个入口、非法字段、重复并发、混合批次、写入失败和重试 |
| 验收标准 | 不产生重复记录，证据与原需求原子落库，测试与文档中的格式一致 |
| 失败处理 | 记录可复现样例、受影响范围和原事务结果，保留已保存工作 |
| 交付报告 | 列出实际改动、导入样例和测试证据，披露已知边界 |
