# 商业机会报告结构

| 序号 | 字段 | 内容 |
| ---: | --- | --- |
| 1 | 产品名称及一句话定位 | 面向谁，完成何种任务 |
| 2 | 目标用户 | 购买者、使用者及细分群体 |
| 3 | 典型场景 | 至少一个具体场景 |
| 4 | 核心痛点 | 频率、耗时、损失及影响 |
| 5 | 真实需求证据 | 独立证据及原始链接 |
| 6 | 实际付费证据 | 已付费、明确意向或未知 |
| 7 | 现有解决方案 | 情况与调查覆盖 |
| 8 | 主要竞品 | 功能、价格、版本及不足 |
| 9 | 免费和开源替代 | 能满足的功能与限制 |
| 10 | 市场缺口 | 尚未满足的任务与人群 |
| 11 | 拟建产品 | 核心工作流和功能 |
| 12 | 我方优势 | 对标方案、改善指标及状态 |
| 13 | 购买及迁移理由 | 价值、替换成本、可复制性 |
| 14 | 优势验证 | 实验、成本、指标和实际结果 |
| 15 | GitHub 技术匹配 | 仓库、版本、复用点和新增功能 |
| 16 | 授权与技术风险 | 代码、权重、数据和依赖审查 |
| 17 | MVP 范围 | 交付边界与研发周期 |
| 18 | 成本 | 研发、运营和维护的估算与依据 |
| 19 | 定价与盈利 | 试销价、市场规模和盈亏平衡假设 |
| 20 | 获客与验证 | 渠道、获客成本假设、实际付费试验 |
| 21 | 综合评分 | 分项、权重、证据与规则版本 |
| 22 | 待验证事项 | 缺失证据、风险及验证任务 |
| 23 | 最终建议 | 推荐立项、继续验证、暂缓或淘汰 |

重要事实附来源链接和调查时间。每条结论标明事实、用户观点、推断、假设或验证结果。销售、利润及规模预测需保留基数、假设、公式和范围。
