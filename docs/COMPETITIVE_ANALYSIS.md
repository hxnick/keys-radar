# 市场及竞争优势分析

1. 确认用户群体、任务、现有做法、频率、损失和付费意愿，标明每项的来源及证据强度。
2. 调查国内外商业软件、免费软件、开源软件、淘宝或闲鱼人工服务，以及 Excel、WPS、ChatGPT、脚本等替代方式。记录市场、语言、关键词、调查日期及覆盖范围。
3. 每个候选保存名称、官网、目标客户、平台、功能与使用条件、版本价格及周期、使用门槛、优势、不足、评价、实际付费证据、信息可信度和待验证事项。按价格页、试用、产品文档和用户评价交叉复核。无公开销量或收入时记为未知。
4. 按真实任务对比现有方案是否满足场景、用户仍遇到的问题、免费方案覆盖和切换成本。没有发现成熟方案时，继续检查需求规模、付费意愿、技术难度、数据许可、获客与售后成本，注明调查覆盖。
5. 将每项拟议优势绑定到具体用户任务、特定竞品及其现有能力。记录我方拟建能力、预期效果和证据、可行性、测试方法与成本、状态及实际结果，回答为何买、为何换、优势能否被复制。可用现有流程与原型的同任务对照测试核实耗时、成功率、费用或上手成本。
6. 完成优势分析后再匹配开源技术。优先审查具备产品形态的仓库并记录版本、维护状态、运行结果、拟复用点和新增开发，分别审查代码、权重、数据及第三方依赖。Star 和 Fork 用于描述项目关注度。

可比较的优势包括价格、效率、体验、功能、本地化、隐私、垂直场景、集成及服务。界面修改、汉化和 AI 入口需要同样证明用户收益。
