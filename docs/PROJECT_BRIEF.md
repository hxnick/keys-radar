# Keys Radar 项目说明

Keys Radar 是 keys-ai 一人 AI 公司的内部商业需求雷达。目标是从国内外真实需求中发现个人或小团队能够开发、销售和维护的标准化软件机会。产品可面向不同领域，是否使用 AI 由场景决定。

真实需求发现 → 市场替代方案调查 → 市场缺口 → 我方优势及验证 → 开源技术匹配 → 商业评估 → 人工立项 → MVP 及付费验证。每个机会都应回答用户遇到了什么问题、目前怎样解决、哪类场景仍未解决、用户为何购买或迁移，以及如何以低成本验证。

| 需求证据 | 判断依据 |
| --- | --- |
| S | 明确有偿需求、真实购买或已经付费，分别记录其性质 |
| A | 多名独立用户反复提出相同需求 |
| B | 用户明确求助、投诉或提出功能建议 |
| C | 教程、产品讨论、推荐等间接信号 |
| D | 产品构想或推断，缺乏直接证据 |

记录用户群体、行业、具体任务、频率、现有办法、时间及经济成本和付费行为。点赞、收藏、浏览量属于互动数据。每条重要事实应回溯到来源和调查时间。

后续模块包括工作台、需求发现、市场及竞品库、开源项目库、商业机会库、项目立项管理和系统设置。机会进度覆盖待分析、需求验证、市场调查、优势验证、技术验证、商业验证、待立项审核、已立项、开发中、已发布、暂缓和淘汰。P0 只有本地人工录入、查询、证据追溯和分组统计。
