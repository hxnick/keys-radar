# 数据源接入规则

P0 只允许人工录入和人工提交 JSON、CSV。原始链接只校验格式和存储，服务不访问链接。

后续优先使用官方 API、合规公开检索、RSS 或用户授权数据。接入前逐个确认平台开放范围、条款、认证要求、限流、允许保存和引用的字段。记录来源、原始链接、发布时间及获取时间、获取路径、规则核实时间和任务状态。访问受限时停止采集，该平台可以继续采用授权数据或人工导入。小红书等受限平台优先人工导入。任何渠道均禁止绕过登录、验证码、访问控制或平台规则。

计划覆盖国内的 V2EX、知乎、酷安、小红书、什么值得买、闲鱼、抖音及应用商店，以及海外的 Reddit、Product Hunt、Hacker News、Indie Hackers、GitHub Issues/Discussions、Apple App Store、Google Play 和 Chrome Web Store。候选清单不等于平台开放或接入完成。

保留完成分析所需的最小公开证据。避免保存无关的姓名、联系方式及其他敏感信息。模拟来源显式标记，统计与真实证据分开。对需要确认的来源、授权和可信度统一标记待验证。
