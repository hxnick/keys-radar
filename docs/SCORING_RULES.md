# 商业机会评分

| 维度 | 权重 |
| --- | ---: |
| 真实需求强度 | 20% |
| 实际付费证据 | 15% |
| 市场未满足程度 | 15% |
| 我方差异化优势 | 20% |
| 开源技术复用程度 | 10% |
| 获客可行性 | 10% |
| 研发及维护成本可控性 | 10% |

各维度以 0–100 分记录，再按权重合成百分制。每项记录分数、依据、证据引用、时间及规则版本。缺证据维度记待验证，保留已核实维度和缺项权重，暂不生成完整总分。评分用于排序及辅助审查，人工审核决定立项。P0 文档规划，P7 实现。
 
初期立项验证目标为至少 20 条独立需求、至少 5 条付费意向或实际付费、覆盖主要直接竞品及免费方案、至少一项可验证优势、完成候选开源授权初审、明确 MVP 与用户付费验证。在小众高价值情形下，由人工记录调整理由。

确认商业授权不合规、依赖未授权获取数据、缺乏需求证据、存在重大法律安全隐私风险、免费替代成熟且无有效差异、无法解释购买理由、核心优势无可行验证方法，或成本超出一人公司承受能力时，不得直接开发。已确认的不合规可淘汰，尚未核实的事项保留待验证或暂缓。
